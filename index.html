About CivMC Rail Atlas

CivMC Rail Atlas is a community map for exploring the railway network of the CivMC Minecraft server. It combines the imported VilyanZ railway dataset with contributor-added map data and a route-planning tool.

Railway data & credits

The original railway base layer displayed by this site is based on the Rails (VilyanZ) dataset supplied for this project.

Credit: VilyanZ — the base railway network and associated station data are credited to VilyanZ. This project does not claim ownership of that original dataset.

Route planner

Enter your current CivMC X/Z coordinates and the X/Z coordinates of your destination. The planner searches the connected railway network for a shortest rail route between the relevant parts of the network.

  • Start/end access: the planner considers the distance from your coordinates to the railway network.
  • Rail route: it searches connected rail segments to find a route.
  • Map display: the selected route is highlighted on the map.

Route results are estimates based on the rail data currently loaded into the map. They do not account for train schedules, line closures, terrain, player-owned restrictions, or other in-game conditions unless represented in the map data.

Community contributions

The map is intended to be publicly viewable while editing remains restricted to approved contributors. The imported base layer is separately protected so ordinary contributors cannot accidentally change the original railway data.

Data note

Railway information can become outdated as CivMC develops. Treat the map as a community reference rather than an official CivMC service.
